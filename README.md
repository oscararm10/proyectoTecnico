# Star Wars Weather API (MVP)
Node.js 20 + TypeScript + Serverless Framework (AWS Lambda)  
Integrates SWAPI and Open-Meteo, uses DynamoDB for storage & cache.

## Quick start
1. Install dependencies: `npm install`
2. Run locally: `npm run dev`
3. Tests: `npm test`
4. Deploy: `npm run deploy` 
5. aws configure (configure AWS credentials first)
